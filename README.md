# Shoe Inventory Management System

## Project Description

This project is a Python-based inventory management system that reads, stores, updates, and displays stock information for shoe products using object-oriented programming.

The program loads inventory data from a text file, creates Shoe objects for each item, and stores them in a list. The system allows the user to view all stock, add new stock items, and update the inventory safely while maintaining proper data validation.

The code demonstrates the use of:

* Classes and objects
* File handling (read/append)
* Lists and loops
* Input validation
* Exception handling
* String representation using the `__str__` method

This project was developed as part of a Python OOP synthesis task.
